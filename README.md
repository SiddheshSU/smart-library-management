# Smart Library Management System

A web-based library management application built with Flask, SQLite, HTML, CSS, and JavaScript.

## Features

- View available books
- Add library members
- Issue and return books
- Track active loans
- View overdue books
- Dashboard statistics
- Health-check endpoint
- Automated testing with Pytest
- Docker deployment
- Jenkins CI/CD pipeline
- Kubernetes deployment using Minikube

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Pytest
- Docker
- Jenkins
- Kubernetes
- Minikube
- AWS EC2
- GitHub
